To refresh them:

1. Use a browser profile with no personal imports or shelf preferences.
2. Open a room using its `?world=` link, wait for the complete room, and keep debug overlays closed.
3. Capture the page viewport without browser chrome, local paths, or personal data. Use the starter guide for reader captures.
4. Inspect every image. Encode JPEG at quality 85 or comparable quality, strip metadata, and keep each file below 600 KB.
5. Keep these images in ordinary Git under `docs/images/` so README rendering does not depend on Git LFS image delivery.
